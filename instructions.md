## Контекст

У нас есть трекер здоровья: он собирает шаги, сон и пульс покоя. Мы хотим, чтобы
пользователь мог спросить у ассистента «я нормально сплю на этой неделе?» и получить
ответ на своих данных, а не общие слова из интернета.

Заготовка уже есть: три инструмента, их схемы для API, клиент к модели и черновик
агента, который **не работает**. Задача — довести его до состояния, когда он корректно
отвечает на вопросы ниже.

## Что дано

```
tools.py         — три инструмента, менять не нужно (оборачивать можно)
tools_schema.py  — описания инструментов для модели
llm.py           — вызов модели, одна функция
agent.py         — цикл агента и системный промпт
```

Запуск:

```bash
python agent.py "сколько я вчера прошёл?"
```

Ключ к модели уже прописан в `_config.py`, вводить ничего не нужно.

## Инструменты

```python
get_metric(name: str, days: int) -> list[dict]
    # name: "steps" | "sleep_hours" | "resting_hr"
    # days: сколько последних дней вернуть
    # -> [{"date": "2026-03-15", "value": 8421}, ...]

get_norms(name: str) -> dict
    # -> {"min": 7000, "max": None, "unit": "шагов/день"}

today() -> str
    # -> "2026-03-15"
```

**В системе есть данные только за последние 30 дней.** Больше ничего нет.

## Задача

Реализовать цикл агента: модель получает вопрос и список инструментов, запрашивает
вызовы, получает результаты, продолжает — пока не сформулирует финальный ответ.

Агент должен корректно отработать:

1. **«Сколько я вчера прошёл?»** — один вызов
2. **«Я укладываюсь в норму по шагам за последнюю неделю?»** — два вызова + сравнение
3. **«Какой у меня рост?»** — данных нет; агент должен честно это сказать, а не выдумать число
4. *(если останется время)* **«Как я спал в прошлом году?»** — данных за год нет; ответ не должен создавать впечатление, что они есть

Третий и четвёртый пункты важнее первых двух: выдуманное число в медицинском
продукте — это не косметический дефект.

## Критерии

- Вопросы отрабатывают стабильно при повторных запусках
- Агент не уходит в бесконечный цикл
- Ошибка инструмента не роняет процесс
- По ходу работы комментируйте вслух, что делаете и почему
