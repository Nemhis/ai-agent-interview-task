# Health Agent

LLM-агент с tool calling поверх данных трекера здоровья.

Заготовка намеренно не доведена до рабочего состояния — это предмет задания.

## Запуск

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env   # впишите ключ OpenRouter
python -m health_agent "сколько я вчера прошёл?"
```

Python 3.10+.

## Задание

**1. Реализовать агента до рабочей версии.**

Он должен корректно отрабатывать четыре вопроса:

- «Сколько я вчера прошёл?»
- «Я укладываюсь в норму по шагам за последнюю неделю?»
- «Какой у меня рост?»
- «Как я спал в прошлом году?»

Последние два важнее первых двух.

Менять можно любой код и любые схемы. Критерии: вопросы отрабатывают стабильно при
повторных запусках, агент не уходит в бесконечный цикл, ошибка инструмента не роняет
процесс.

**2. Составить план.**

Как вы разбили задачу и в каком порядке шли. Коротко, в свободной форме — важен ход
рассуждений, а не оформление.

**3. Найти ошибки и архитектурные пробелы, если они есть.**

Отдельным списком: что нашли, почему считаете это проблемой, что предлагаете. Сюда
же — то, что чинить не стали и почему.
